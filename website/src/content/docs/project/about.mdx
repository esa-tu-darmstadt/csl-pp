csl++ is developed by the Embedded Systems and Applications group at TU Darmstadt. It is not a product of Cerebras Systems; CSL, `cslc` and the Cerebras SDK are.

## Publication

The design of the async extension and of its stackful lowering is described in the paper *Structured Coroutines for the Wafer-Scale Engine*, which has been accepted for publication at CGO 2027, the International Symposium on Code Generation and Optimization, held in Salt Lake City, Utah, USA, from 20 to 24 March 2027 together with HPCA, PPoPP and CC. The paper is not published yet; we look forward to presenting it there.

## Reporting problems

Report bugs and questions in the [issue tracker](https://github.com/esa-tu-darmstadt/csl-pp/issues) of the repository. Report security vulnerabilities privately, as described in `SECURITY.md` of the repository. For a wrong result or a crash, include:

- the version of the Cerebras SDK and the target architecture;
- the `csl-pp` command line;
- a small program that shows the problem, ideally one PE program and its layout file.

`csl-pp` is intended to report every error that `cslc` reports. If `cslc` reports an error for a program that `csl-pp` accepted, please report it as a bug.
