title: Overview
description: List of the extensions csl++ adds to CSL.
---

csl++ is CSL with the extensions listed on this page. Every CSL program is a csl++ program. `csl-pp` translates csl++ to vanilla CSL, so the extensions need no support from `cslc`.

## Declarations and statements

| Syntax | Meaning | Page |
| --- | --- | --- |
| `async fn f(...) T { ... }` | A function that can suspend. | [Async functions and tasks](../async/) |
| `async task t() void { ... }` | A task that can suspend. | [Async functions and tasks](../async/) |
| `suspend;` | Ends the current run of the task; the next activation continues after it. | [Async functions and tasks](../async/#suspend) |
| `fn f(...) max_recursion_depth(N) T` | Bounds the recursion of `f` for stack sizing. | [Stacks](../stacks/#max_recursion_depthn) |
| `fn f(...) stack_size(N) T` | Declares the stack use of `f` in bytes. | [Stacks](../stacks/#stack_sizen) |

`async` and `suspend` are only keywords in these positions; elsewhere they are ordinary identifiers.
