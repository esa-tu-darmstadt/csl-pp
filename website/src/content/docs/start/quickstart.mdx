## Compile a vanilla CSL program

`csl-pp` takes the same arguments as `cslc`, and every CSL program is a csl++ program. Copy the first GEMV tutorial of the SDK and compile it with `csl-pp` in place of `cslc`:

```bash
cp -r ~/cerebras-sdk/csl-extras-*/examples/tutorials/gemv-01-complete-program .
cd gemv-01-complete-program
csl-pp --arch=wse3 ./layout.csl --fabric-dims=8,3 --fabric-offsets=4,1 \
  -o out --memcpy --channels 1
cs_python run.py --name out
```

`csl-pp` writes the CSL it generates to a temporary directory and runs `cslc` on it. `out/` contains the output of `cslc`, and `run.py` runs on the simulator as with `cslc`. `cs_python` is in the SDK directory.

## Compile a csl++ program

The example programs of this documentation are in the csl++ repository. Clone it and run the first program of the tutorial:

```bash
git clone https://github.com/esa-tu-darmstadt/csl-pp.git
cd csl-pp/website/examples/tutorial/1-suspend
./commands_wse3.sh
```

The script compiles the program with `csl-pp` and runs its host program on the simulator:

<Example file="tutorial/1-suspend/commands_wse3.sh" />

The program consists of three PEs in a row. The middle PE receives a value from each of its two neighbors and adds them, and the host program prints the result:

```
1.5 + 2.25 = 3.75
SUCCESS!
```

The middle PE does this in one task, which suspends while it waits for a value:

<Example file="tutorial/1-suspend/src/receiver.csl" region="task" />

The [Tutorial](../../tutorial/) explains this program and develops it further. [csl-pp](../../tools/csl-pp/) describes the options of `csl-pp` and the files it writes.
